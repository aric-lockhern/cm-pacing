Budgets

One account column (e.g. A), then the budget column(s) for each channel. Any channel can take a comma-separated list of month columns (e.g. P,Q,R) — newest month last; each column is stored as that month's billed, so the Overview keeps full month-by-month history. A single letter = just the current month. LSA additionally sums its months into a running pool for burn-down pacing. Each month, append the new month's column (don't overwrite) so history is preserved. Budgets auto-sync once a day; Sync any time you change the sheet. Share the sheet with the account that runs the gateway.

Meta / Facebook import

Pulls daily Meta spend + metrics from your DataSlayer sheet into the tool. Franchise = the Campaign tag — campaigns with no tag are ignored (they show as inactive). Share the DataSlayer sheet with the account that runs the gateway. Auto-updates every day on its own (a background job at ~6am, plus a catch-up on the first app load each day) — you only need Sync if the columns/range change.

Budget moves

Log budget shifted between channels for a franchise — e.g. you moved spend from Google into LSA. This never edits the master billing sheet (the client's total bill is unchanged); it just adjusts each channel's pacing target so Google doesn't look under-pacing and LSA over. Amounts are in billed dollars (same as the budget sheet). The move carries forward from its month and depletes as the destination spends through it — once the moved amount is spent, targets revert to the sheet automatically (see Remaining below). Void a row to cancel it early.
